Cloud Computing Explained

A simple guide to the future of infrastructure

What is Cloud Computing?

Cloud computing is the delivery of computing services—including servers, storage, databases, networking, software, analytics, and intelligence—over the Internet ("the cloud") to offer faster innovation, flexible resources, and economies of scale.

Core Service Models

Model Stands For Description Examples
IaaS Infrastructure as a Service Provides virtualized computing resources over the internet. You manage the OS and data. AWS EC2, Google Compute Engine
PaaS Platform as a Service Provides hardware and software tools over the internet, typically for application development. Heroku, Google App Engine
SaaS Software as a Service Delivers software applications over the internet, on demand and typically on a subscription basis. Google Workspace, Salesforce

Deployment Models

Public Cloud

Owned and operated by third-party cloud service providers, delivering computing resources over the public internet. All hardware is managed by the provider.

Private Cloud

Cloud computing resources used exclusively by a single business or organization. It can be physically located on the company's on-site datacenter.

Hybrid Cloud

Combines public and private clouds, bound together by technology that allows data and applications to be shared between them.
