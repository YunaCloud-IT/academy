# 🚀 Academy

Welcome to the YunaCloud Academy repository. This is the central ecosystem for technical training, onboarding materials, and professional development tracks designed for engineers and IT professionals within the YunaCloud network.

---------------------------

## 📖 Overview

The Academy is built to bridge the gap between theoretical knowledge and production-ready skills. It contains curated paths for:

- **Cloud Infrastructure** (GCP)

- **DevOps & Automation** (Terraform, Ansible, CI/CD)

- **Modern Development** (Backend, Frontend, Fullstack)

- **Security & Compliance**

---------------------------

## 🛠 Getting Started

### Prerequisites

To get the most out of these materials, we recommend:

- A basic understanding of Linux/Unix command line.

- Git installed locally.

- A code editor (VS Code recommended).

### How to use this repository

1. **Clone the Repo**:

```
git clone https://github.com/YunaCloud-IT/academy.git
```

2. **Navigate to a Module**: Choose a topic from the folder.

3. **Follow the README**: Each subdirectory contains its own specific instructions and lab goals.
